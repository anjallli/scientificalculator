# Scientific Calculator

## BSC CS Project

Scientific Calculator is a Java-based application developed to perform both basic and advanced mathematical calculations through a simple and user-friendly interface.
The application supports operations such as addition, subtraction, multiplication, division, square roots, powers, trigonometric functions, and other scientific calculations.
This project focuses on implementing mathematical logic, user interaction handling, and efficient calculation processing while demonstrating core Java programming concepts and application development skills.

Tools & Technologies Used: Java, Java Swing/AWT, Eclipse/VS Code.
